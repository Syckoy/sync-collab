Synchro complete du serveur local (toi + ton ami)
=================================================

Les deux lancent le script. Vous echangez un code une seule fois.
Ensuite les PCs se connectent et recopient TOUT le dossier "server local"
(environ 32 Go la premiere fois). Les fois suivantes : seulement ce qui a change.

PREMIERE FOIS — TOI
1. Double-clic sur sync.bat
2. Le script affiche TON CODE (une longue suite de lettres)
3. Envoie ce code a ton ami (Discord, etc.)

PREMIERE FOIS — TON AMI
1. Il cree un dossier vide, par exemple :
   C:\Users\Lui\Desktop\server local
2. Il copie DEDANS tout le dossier sync-collab (celui-ci)
3. Il lance sync.bat
4. Il colle TON code quand le script le demande
5. Il t'envoie SON code
6. De ton cote, tu colles son code aussi

Les deux scripts doivent rester OUVERTS pendant la copie.
La premiere synchro peut durer longtemps (32 Go). Ne fermez pas.

ENSITE
Chaque fois que vous voulez mettre a jour : vous lancez tous les deux sync.bat.
Le code est deja enregistre, ca se reconnecte tout seul.
Seuls les fichiers nouveaux / modifies partent.

ASTUCE VITESSE
Si Windows demande le pare-feu : autorise Syncthing (reseau prive ET public).
Sinon ca passe par un relais plus lent, mais ca marche quand meme a distance.
